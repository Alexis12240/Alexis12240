## Sobre mí

Estudio **Ingeniería Mecatrónica** y desarrollo soluciones que integran sistemas físicos con aplicaciones digitales. Me interesan especialmente la adquisición de datos, el monitoreo en tiempo real, el control automático y la creación de herramientas de ingeniería prácticas y reproducibles.

## Áreas de trabajo

| Especialidad | Enfoque |
| :--- | :--- |
| **Sistemas embebidos** | Firmware, sensores, buses de comunicación y arquitectura de dispositivos conectados. |
| **Automatización y control** | Instrumentación, actuadores, adquisición de señales y supervisión de procesos. |
| **Software de ingeniería** | Interfaces de monitoreo, dashboards, aplicaciones locales y servicios web. |
| **Procesamiento de datos** | Python, MATLAB, visión por computadora y experimentación con IA aplicada. |
